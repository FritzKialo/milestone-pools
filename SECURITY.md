# Security

This software is unaudited and runs on a test network only. There is no bug bounty.

## Reporting a vulnerability

Please email **frenkiac@frenkia.com** with the subject "Security report". Describe what you found and how to reproduce it, and please do not post it publicly before it has been looked at.

## Questions and bug reports

Use the project's issue tracker for ordinary bugs and questions, or the Support page in the app.

## Scope

In scope: the contract in `packages/hardhat/contracts/MilestonePools.sol` and the web app in `packages/nextjs`. The test USDC token in the same repository is a mock for test networks and is out of scope.
